`@nodecfdi/xml-resource-retriever` es una librería para Node.js diseñada para descargar recursivamente recursos XML desde internet hacia un directorio local, reescribiendo automáticamente las referencias entre archivos a rutas relativas para que puedan utilizarse sin conexión.

Es especialmente útil en el ecosistema CFDI para descargar esquemas de validación (`.xsd`) y hojas de transformación de cadena original (`.xslt`) publicados por el SAT, evitando depender de la disponibilidad de los servidores remotos en tiempo de ejecución.

## Características clave

- **Soporte listo para XSD y XSLT**: incluye [`XsdRetriever`](/packages/xml-resource-retriever/usage/xsd-retriever) y [`XsltRetriever`](/packages/xml-resource-retriever/usage/xslt-retriever) para resolver `import` e `include` de forma recursiva.
- **Reescritura a rutas relativas**: cada recurso descargado actualiza sus atributos `schemaLocation` o `href` para apuntar al archivo local correspondiente.
- **Descarga concurrente controlada**: descarga dependencias hermanas en paralelo respetando un límite configurable de concurrencia y previniendo ciclos infinitos.
- **Descargador nativo con `fetch`**: [`NodeDownloader`](/packages/xml-resource-retriever/usage/node-downloader) utiliza `fetch` nativo de Node.js con soporte para `timeoutMs`, `maxBytes`, `RequestInit` y escritura atómica.
- **Seguridad integrada**: restringe protocolos a `http:` y `https:`, previene *path traversal* y valida que cada archivo descargado sea un XML válido y no vacío.
- **Extensible**: permite crear [retrievers personalizados](/packages/xml-resource-retriever/advanced/custom-retrievers) y [descargadores personalizados](/packages/xml-resource-retriever/advanced/custom-downloaders).

## Requisitos

| Entorno | Versión soportada |
| --- | --- |
| Node.js | `^22.13.0 \|\| ^24 \|\| ^26` |
| Sistema de módulos | ESM (`"type": "module"`) |

::note
Este paquete está diseñado exclusivamente para Node.js (utiliza `node:fs`, `node:path`, `node:stream` y `node:crypto`) y no está destinado a ejecutarse en navegadores.
::
