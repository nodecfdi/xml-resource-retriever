Instala `@nodecfdi/xml-resource-retriever` usando tu gestor de paquetes preferido.

::code-group
```bash [pnpm]
pnpm add @nodecfdi/xml-resource-retriever
```

```bash [npm]
npm install @nodecfdi/xml-resource-retriever
```

```bash [yarn]
yarn add @nodecfdi/xml-resource-retriever
```

```bash [bun]
bun add @nodecfdi/xml-resource-retriever
```
::

::note
`@nodecfdi/xml-resource-retriever` es un paquete **ESM puro** que requiere Node.js `^22.13.0`, `^24` o `^26`. Asegúrate de que tu proyecto use `"type": "module"` en `package.json` o archivos con extensión `.mjs`.
::

::tip
¿Estás actualizando desde la versión `2.x`? Revisa la [guía de migración a v3.0.0](/packages/xml-resource-retriever/upgrading/v2-to-v3) para conocer los cambios rompientes.
::

## Exportaciones disponibles

El paquete expone dos puntos de entrada:

- `@nodecfdi/xml-resource-retriever`: clases principales (`XsdRetriever`, `XsltRetriever`, `NodeDownloader`, `AbstractBaseRetriever`, `AbstractXmlRetriever`) y [utilidades](/packages/xml-resource-retriever/api-reference/utilities).
- `@nodecfdi/xml-resource-retriever/types`: interfaces y tipos de TypeScript (`RetrieverInterface`, `DownloaderInterface`, `NodeDownloaderOptions`, `SearchElement`, `UrlParts`).

## Verificación rápida

::steps
### Crea un script de prueba

```ts [download-xsd.ts]
import { XsdRetriever } from '@nodecfdi/xml-resource-retriever';

const retriever = new XsdRetriever('./storage');
const localPath = await retriever.retrieve(
  'http://www.sat.gob.mx/sitio_internet/cfd/4/cfdv40.xsd',
);

console.log('Archivo principal:', localPath);
console.log('Total de archivos descargados:', Object.keys(retriever.retrieveHistory()).length);
```

### Ejecuta el script

```bash
node download-xsd.ts
```

Si la ejecución termina sin errores, encontrarás el esquema y todas sus dependencias dentro de `./storage/www.sat.gob.mx/...` con sus rutas `schemaLocation` reescritas de forma relativa.
::
