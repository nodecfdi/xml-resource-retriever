`XsltRetriever` extiende [`AbstractXmlRetriever`](/packages/xml-resource-retriever/api-reference/retrievers) para descargar recursivamente hojas de transformación XSLT dentro del namespace `http://www.w3.org/1999/XSL/Transform`.

Para cada hoja procesada, busca y reescribe a rutas relativas los siguientes elementos:

| Elemento | Atributo |
| --- | --- |
| `import` | `href` |
| `include` | `href` |

## Descarga recursiva con `retrieve()`

El caso de uso más común es descargar la hoja de transformación de la cadena original del SAT junto con todos los complementos que incluye.

```ts [scripts/retrieve-xslt.ts]
import { XsltRetriever } from '@nodecfdi/xml-resource-retriever';

const retriever = new XsltRetriever('./storage/xslt');
const localXslt = await retriever.retrieve(
  'http://www.sat.gob.mx/sitio_internet/cfd/4/cadenaoriginal_4_0/cadenaoriginal_4_0.xslt',
);

console.log('XSLT local:', localXslt);
console.log('Recursos descargados:', Object.keys(retriever.retrieveHistory()).length);
```

### Reescritura de atributos `href`

Al igual que en XSD, las referencias absolutas o relativas encontradas en `xsl:import` y `xsl:include` se resuelven contra la URL del documento actual, se descargan y se reescriben como rutas relativas:

```xml
<!-- Antes -->
<xsl:include href="http://www.sat.gob.mx/sitio_internet/cfd/4/cadenaoriginal_4_0/utilerias.xslt" />

<!-- Después -->
<xsl:include href="utilerias.xslt" />
```

## Personalizar el descargador

Los servidores del SAT suelen presentar latencia elevada o respuestas lentas. Puedes configurar un `NodeDownloader` con mayor tiempo de espera o encabezados personalizados y pasarlo al constructor (o mediante `setDownloader()`):

```ts [scripts/retrieve-xslt-custom.ts]
import { NodeDownloader, XsltRetriever } from '@nodecfdi/xml-resource-retriever';

const downloader = new NodeDownloader({
  timeoutMs: 60_000,
  headers: {
    'User-Agent': 'MiAplicacion/1.0',
  },
});

const retriever = new XsltRetriever('./storage/xslt', downloader);
await retriever.retrieve(
  'http://www.sat.gob.mx/sitio_internet/cfd/4/cadenaoriginal_4_0/cadenaoriginal_4_0.xslt',
);
```

::note
Si algún archivo enlazado devuelve error HTTP, está vacío o no es un XML válido, `retrieve()` espera a que concluyan las descargas hermanas en curso y luego propaga el error, evitando que queden operaciones huérfanas escribiendo en disco.
::

## Descarga individual y cálculo de rutas

`XsltRetriever` hereda los métodos `download(url)`, `buildPath(url)`, `getBasePath()`, `getDownloader()`, `setDownloader(downloader)` y `retrieveHistory()` de [`AbstractBaseRetriever`](/packages/xml-resource-retriever/api-reference/retrievers).
