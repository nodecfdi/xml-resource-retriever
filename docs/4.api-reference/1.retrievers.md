Todas las clases de retrievers se exportan como exportaciones nombradas desde `@nodecfdi/xml-resource-retriever`.

```ts
import {
  AbstractBaseRetriever,
  AbstractXmlRetriever,
  XsdRetriever,
  XsltRetriever,
} from '@nodecfdi/xml-resource-retriever';
```

## `AbstractBaseRetriever`

Clase base abstracta que implementa `RetrieverInterface`.

### Constructor

```ts
declare abstract class AbstractBaseRetriever {
  protected constructor(basePath: string, downloader?: DownloaderInterface);
}
```

Si no se proporciona `downloader`, utiliza `new NodeDownloader()`.

### Métodos públicos

| Método | Firma | Descripción |
| --- | --- | --- |
| `getBasePath` | `() => string` | Devuelve la ruta base configurada en el constructor. |
| `getDownloader` | `() => DownloaderInterface` | Devuelve la instancia actual del descargador. |
| `setDownloader` | `(downloader: DownloaderInterface) => void` | Reemplaza el descargador utilizado por el retriever. |
| `buildPath` | `(url: string) => string` | Calcula la ruta local segura donde se guardará `url` usando `resolveLocalFilePath`. Lanza `Error` si la URL es inválida o intenta salir de `basePath`. |
| `download` | `(url: string) => Promise<string>` | Descarga `url` sin sus dependencias, crea los directorios necesarios, ejecuta `checkIsValidDownloadedFile` y devuelve la ruta local. |
| `retrieve` | `(url: string) => Promise<string>` | Método abstracto para descargar un recurso y sus dependencias. |
| `retrieveHistory` | `() => Record<string, string>` | Devuelve una copia plana (`Object.fromEntries`) del historial de la última operación `retrieve()` (`{ [url]: localPath }`). |

### Métodos protegidos

| Método | Firma | Descripción |
| --- | --- | --- |
| `clearHistory` | `() => void` | Vacía el mapa interno de historial. |
| `addToHistory` | `(source: string, localPath: string) => void` | Registra una URL y su ruta local en el historial. |
| `hasInHistory` | `(source: string) => boolean` | Indica si una URL ya fue registrada en el historial. |
| `getFromHistory` | `(source: string) => string \| undefined` | Obtiene la ruta local registrada para `source`. |
| `historySize` | `() => number` | Devuelve la cantidad de recursos registrados en el historial. |
| `urlParts` | `(url: string) => UrlParts \| undefined` | Analiza una URL HTTP/HTTPS delegando en `parseHttpUrlParts`. |
| `checkIsValidDownloadedFile` | `(source: string, localPath: string) => Promise<void>` | Método abstracto ejecutado tras descargar un archivo en `download()`. |

## `AbstractXmlRetriever`

Extiende `AbstractBaseRetriever` e implementa la descarga recursiva y concurrente de documentos XML con reescritura de rutas relativas.

### Constructor

```ts
declare abstract class AbstractXmlRetriever extends AbstractBaseRetriever {
  public constructor(basePath: string, downloader?: DownloaderInterface);
}
```

### Métodos públicos

- `retrieve(url: string): Promise<string>`: limpia el historial y descarga `url` junto con todos los recursos enlazados de forma recursiva, reescribiendo los atributos coincidentes a rutas relativas.

### Métodos protegidos

| Método | Firma | Valor por defecto / Comportamiento |
| --- | --- | --- |
| `checkIsValidDownloadedFile` | `(source: string, localPath: string) => Promise<void>` | Llama a `validateDownloadedXmlFile(source, localPath)`. |
| `maxDepth` | `() => number` | `50` |
| `maxResources` | `() => number` | `500` |
| `maxConcurrentDownloads` | `() => number` | `6` |
| `searchNamespace` | `() => string` | Abstracto. Namespace XML donde se buscan los elementos enlazados. |
| `searchElements` | `() => (SearchElement \| Record<string, string>)[]` | Abstracto. Lista de pares `{ element, attribute }` a inspeccionar y reescribir. |

---

## `XsdRetriever`

Extiende `AbstractXmlRetriever` para esquemas XML (XSD).

- **`searchNamespace()`**: `'http://www.w3.org/2001/XMLSchema'`
- **`searchElements()`**:
  - `{ element: 'import', attribute: 'schemaLocation' }`
  - `{ element: 'include', attribute: 'schemaLocation' }`

---

## `XsltRetriever`

Extiende `AbstractXmlRetriever` para hojas de transformación XSLT.

- **`searchNamespace()`**: `'http://www.w3.org/1999/XSL/Transform'`
- **`searchElements()`**:
  - `{ element: 'import', attribute: 'href' }`
  - `{ element: 'include', attribute: 'href' }`
