Además de las clases principales, `@nodecfdi/xml-resource-retriever` re-exporta sus utilidades internas para reutilizarlas directamente en [retrievers personalizados](/packages/xml-resource-retriever/advanced/custom-retrievers) o herramientas propias.

```ts
import {
  assertAllowedHttpUrl,
  buildAbortSignal,
  createByteLimitTransform,
  isXmlMimeType,
  parseHttpUrlParts,
  relativePath,
  relativeToAbsoluteUrl,
  resolveLocalFilePath,
  simplifyPath,
  stripUtf8Bom,
  validateDownloadedXmlFile,
  validateNonNegativeFinite,
} from '@nodecfdi/xml-resource-retriever';
```

## Utilidades de rutas

### `simplifyPath(inputPath: string): string[]`

Normaliza una ruta separada por `/` resolviendo segmentos `.` y `..`, y devuelve el arreglo de segmentos resultantes.

```ts
simplifyPath('/a/b/../c/./file.xsd');
// ['', 'a', 'c', 'file.xsd']
```

### `relativePath(sourceFile: string, destinationFile: string): string`

Calcula la ruta relativa desde el directorio de `sourceFile` hacia `destinationFile`.

```ts
relativePath('/storage/xsd/entities/ticket.xsd', '/storage/xsd/articles/books.xsd');
// '../articles/books.xsd'
```

## Utilidades de URL

### `assertAllowedHttpUrl(rawUrl: string): URL`

Parsea `rawUrl` con `new URL(rawUrl)` y verifica que el protocolo sea `http:` o `https:`. Lanza `Error` si el protocolo no está permitido o `TypeError` si la URL es inválida.

### `parseHttpUrlParts(url: string): UrlParts | undefined`

Analiza una URL HTTP/HTTPS y devuelve `{ scheme, host, port, path }`. Retorna `undefined` si la URL está mal formada, contiene bytes nulos (`\0` o `%00`), carece de `hostname` o usa un protocolo distinto de `http:`/`https:`.

### `resolveLocalFilePath(basePath: string, url: string): string`

Convierte una URL HTTP/HTTPS a su ruta local bajo `basePath` (`${normalizedBase}/${parts.host}${parts.path}`). Lanza `Error` si la URL es inválida o si la ruta resultante escapa de `basePath` (*path traversal*).

### `relativeToAbsoluteUrl(url: string, currentUrl: string): string`

Resuelve una referencia `url` (absoluta, protocol-relative `//...` o relativa) respecto a `currentUrl`, normalizando barras duplicadas en el pathname.

```ts
relativeToAbsoluteUrl('../articles/books.xsd', 'http://example.com/xsd/entities/ticket.xsd');
// 'http://example.com/xsd/articles/books.xsd'
```

## Utilidades de streams y señales

### `validateNonNegativeFinite(value: number, name: string): number`

Verifica que `value` sea un número finito mayor o igual a `0`. En caso contrario, lanza `RangeError`.

### `createByteLimitTransform(maxBytes: number): Transform`

Crea un `Transform` stream de `node:stream` que contabiliza los bytes recibidos y falla con `Error` en cuanto el total supera `maxBytes`.

### `buildAbortSignal(timeoutMs: number, userSignal?: AbortSignal | null): AbortSignal | undefined`

Construye un `AbortSignal` a partir de `timeoutMs` (si es mayor a `0`) y una señal opcional del usuario. Cuando ambos están presentes, los combina mediante `AbortSignal.any([userSignal, timeoutSignal])`.

## Utilidades de validación XML

### `stripUtf8Bom(content: string): string`

Elimina el carácter BOM UTF-8 (`\uFEFF`) al inicio de una cadena si está presente.

### `isXmlMimeType(mimeType: string | undefined): boolean`

Devuelve `true` cuando `mimeType` es `'application/xml'`, termina en `'+xml'` o comienza con `'text/'`.

### `validateDownloadedXmlFile(source: string, localPath: string): Promise<void>`

Valida que `localPath` no esté vacío y tenga un tipo MIME compatible con XML (inspeccionando contenido binario con `file-type` y extensión con `mime`). Si la validación falla, elimina `localPath` del disco y lanza `Error`.
